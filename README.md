# STM32智能手表项目

## 项目简介

这是一个基于STM32F103微控制器的多功能智能手表项目，作为嵌入式系统课程设计完成。该项目充分利用了STM32的片内资源，实现了丰富的功能和友好的用户界面。

## 主要功能

1. **实时时钟** - 显示完整的日期和时间，支持手动设置
2. **电池电量监测** - 实时显示电池电压和电量百分比
3. **秒表计时** - 支持开始、暂停、清零操作
4. **手电筒** - LED灯控制功能
5. **姿态检测** - MPU6050六轴传感器，水平仪功能
6. **小游戏** - 经典的小恐龙跳跃游戏
7. **图形化UI** - 流畅的菜单动画和反色选中效果
8. **低功耗** - 长按关机功能，RTC备份域保持时间

## 硬件配置

### 核心控制器
- **MCU**: STM32F103C8T6/RCT6
- **主频**: 72MHz
- **Flash**: 64KB/128KB
- **RAM**: 20KB

### 外设模块
- **显示屏**: 0.96寸 OLED (128x64, I2C接口)
- **传感器**: MPU6050 六轴姿态传感器
- **按键**: 3个独立按键（上一项、下一项、确认/长按关机）
- **LED**: 用于手电筒功能
- **ADC**: 电池电压检测

### 引脚分配
```
GPIOA:
  PA0 - ADC1_CH0 (电池电压检测)
  PA4 - Key3 (确认/长按关机)
  PA6 - Key2 (下一项)

GPIOB:
  PB1  - Key1 (上一项)
  PB8  - OLED_SCL (软件I2C)
  PB9  - OLED_SDA (软件I2C)
  PB10 - MPU6050_SCL (软件I2C)
  PB11 - MPU6050_SDA (软件I2C)
  PB12 - BAT_ADC_EN (ADC电源控制)
  PB13 - CTL (主电源控制)
  PB15 - LED (手电筒)
```

## 片内资源使用

本项目使用了8种STM32片内资源，完全满足课程设计要求（5个以上）：

| 编号 | 片内资源 | 应用场景 |
|-----|---------|---------|
| 1 | **GPIO** | 按键输入、LED控制、I2C通信 |
| 2 | **ADC** | 电池电压检测（12位精度） |
| 3 | **TIMER** | TIM2定时器中断，多任务调度 |
| 4 | **RTC** | 实时时钟，LSE时钟源 |
| 5 | **NVIC** | 中断优先级管理 |
| 6 | **SysTick** | 微秒/毫秒级延时 |
| 7 | **BKP** | 备份寄存器，RTC配置保存 |
| 8 | **I2C（软件）** | OLED和MPU6050通信 |

## 软件架构

项目采用分层模块化设计：

```
应用层 (Application Layer)
├── menu.c/h          - UI菜单系统
├── dino.c/h          - 游戏应用
└── SetTime.c/h       - 时间设置应用

硬件抽象层 (HAL)
├── OLED.c/h          - OLED显示驱动
├── Key.c/h           - 按键驱动
├── LED.c/h           - LED驱动
├── MPU6050.c/h       - 姿态传感器驱动
├── AD.c/h            - ADC驱动
└── MyI2C.c/h         - 软件I2C驱动

系统层 (System Layer)
├── MyRTC.c/h         - RTC时钟管理
├── Timer.c/h         - 定时器管理
└── Delay.c/h         - 延时函数
```

## 开发环境

- **IDE**: Keil MDK-ARM V5.x
- **编译器**: ARMCC
- **固件库**: STM32F10x标准外设库 V3.5.0
- **调试器**: ST-Link V2
- **程序大小**: ROM约28KB，RAM约2.7KB

## 编译和烧录

1. 使用Keil MDK打开项目
2. 选择目标设备（STM32F103C8/RC）
3. 编译项目（F7）
4. 连接ST-Link调试器
5. 下载到芯片（F8）

## 项目特色

1. **图形化UI** - 美观的菜单界面，流畅的动画切换
2. **模块化设计** - 代码结构清晰，易于维护和扩展
3. **软件I2C** - 灵活的引脚配置，节省硬件资源
4. **多任务处理** - 定时器中断实现伪并行任务
5. **电源管理** - 电量监测、长按关机、RTC备份
6. **丰富功能** - 时钟、秒表、游戏、传感器等多种应用
